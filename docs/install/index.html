Release —

Everything on the panel is erased, including its configuration. An already installed panel has its own updater — use that one.

Next steps

  1. The panel starts a Wi-Fi network called RCT-Panel, no password. Join it.
  2. A configuration page opens. Enter the network and the inverter's address.
  3. The panel joins your network and shows the address it got on its own screen — Service page, top left. Open it there, or at http://rct-panel.local if your browser resolves such names.

Troubleshooting

  • A dialog asking which port to use has to appear. If it does not, the panel is not enumerating: another USB cable, another port, cover off.
  • The flash stopped halfway — run it again. Everything is erased first anyway.
  • Nothing after the flash — press reset once.
